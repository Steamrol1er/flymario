An honest negative result

The trained agent passed zero pipes in 2000 episodes. This isn't a rendering trick or a cherry-picked bad run — it's the real outcome. Flappy Bird needs continuous positional tracking every frame, unlike the platformer's single "jump at the gap" decision, and that turned out to be genuinely harder for a linear Kenyon-cell readout trained with this simple actor-critic rule.

What we found along the way

Debugging this surfaced a real bug: unnormalized Kenyon-cell activity (~100 simultaneously active units, unbounded magnitude) made the mushroom body's value estimate swing wildly, saturating the actor's weights to their clamp bounds within the first ~50 episodes and freezing the policy for the rest of training. Adding divisive normalization (a real mechanism in actual neural circuits) fixed that specific instability — but the agent still didn't learn to solve the task. The hand-coded reference tab shows the environment genuinely is solvable (score 3, no learning involved) — the gap is in the learning method, not the game.
