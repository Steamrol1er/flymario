Why this region

The gnathal ganglion (GNG) — the modern name for what was called the subesophageal zone — is where gustatory (taste/sugar) sensory afferents arrive and where feeding premotor and motor circuits, including MN9, sit. That anatomical fact comes from the published fly neuroanatomy literature, not from this simulation.

What's real vs. approximate

The brain surface and GNG geometry are a real public 3D reconstruction (VirtualFlyBrain's JFRC2 template domains). The pulse timing is real simulated activity from the same LIF run as the network view. What's not shown here: exactly which of the 396 active neurons sit inside this mesh — that needs FlyWire's own 3D coordinates, which require Codex account access this project doesn't have yet (see docs/STATUS.md). The network-graph view shows those individual neurons instead, without real 3D placement.
