Why not real Mario?

gym-super-mario-bros/nes-py need a C++ build toolchain this environment doesn't have, and there's no legal ROM to load even if it did. This is an original game with the same shape of problem — run right, jump gaps and an obstacle, avoid a patrolling enemy, reach a flag — so the real learning code plugs in unchanged.

What's real vs. simplified

The dopamine three-factor rule and TD actor-critic are the same code used elsewhere in this project. They run on the toy odor→KC→MBON circuit, not the real 138,639-neuron FlyWire connectome — identifying real KC/MBON/dopamine neurons there needs FlyWire Codex annotations this project doesn't have. The agent wins sometimes (real data, shown above) but hasn't converged to reliably solving the level — an honest partial result.
